# Правила и регламент (база знаний хакатона)

Правила проведения хакатона, регламент, расписание, дедлайны. Собирается из чанков и источников.

## Правила проведения
- Продолжительность хакатона — 39 часов.
- Решение загружается в формате ZIP (только ZIP) с исходным кодом.
- Обязательны обе автоматические проверки: качество кода и нагрузочное тестирование. Решение, не прошедшее проверку качества кода или не развёрнутое для нагрузочного тестирования, не будет учтено.
- Использование своих кодинговых агентов крайне не рекомендуется (пайплайн проверки выстроен под рекомендуемые инструменты).
- Рекомендуемые языки: Python, Java, Go.
- Рекомендуемые инструменты: VS Code, Kilo Code, модель DeepSeek V4 Flash (Альфа-Ген).
