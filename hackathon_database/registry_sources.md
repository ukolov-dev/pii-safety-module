# Реестр источников (база знаний хакатона)

Реестр исходных материалов о проведении хакатона. Каждый источник получает ID вида `SRC-NNN` (NNN — номер).

## Формат записи
```yaml
SRC-NNN:
  происхождение: <откуда получен>
  дата: <YYYY-MM-DD>
  статус: <новый | в обработке | обработан | отклонен>
  ссылки: <пути к файлам в RAW/ или внешние ссылки>
  описание: <краткое описание>
```

## Записи
```yaml
SRC-001:
  происхождение: задание на хакатон (ТЗ трека)
  дата: 2026-09-22
  статус: обработан
  ссылки: RAW/ds.pdf
  описание: ТЗ трека «Модуль безопасности персональных данных» — условия, автоматическая проверка, контракт API, приложения A и B.

SRC-002:
  происхождение: задание на хакатон (регламент и ТЗ)
  дата: 2026-09-22
  статус: обработан
  ссылки: RAW/requirements.md
  описание: Регламент хакатона (расписание, материалы для сдачи, автоматические проверки) и ТЗ на систему.

SRC-003:
  происхождение: онбординг
  дата: 2026-09-22
  статус: обработан
  ссылки: RAW/Сегодня_все_команды,_работающие_с_L.txt
  описание: Онбординг — проблематика, ключевые/функциональные/нефункциональные требования, автоматическая проверка.

SRC-004:
  происхождение: транскрипт брифинга открытия
  дата: 2026-09-22
  статус: обработан
  ссылки: RAW/2026-09-22-opening-transcript.txt
  описание: Транскрипт брифинга открытия хакатона — регламент, критерии оценки, ответы на вопросы участников.

SRC-005:
  происхождение: авторизованный портал участника хакатона
  дата: 2026-09-23
  статус: обработан
  ссылки: RAW/2026-09-23-hackathon-portal.md; https://reg.vibecoding-hackathon.ru/results/data-science; https://reg.vibecoding-hackathon.ru/results/submitsolution; https://reg.vibecoding-hackathon.ru/tasks
  описание: "Актуальный интерфейс проверки и финальной загрузки: сроки, попытки, поля формы и лимиты файлов."
```
