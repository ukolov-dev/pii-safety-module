# Обзор (база знаний хакатона)

Обзорное описание хакатона. Собирается из чанков и источников.

## Назначение
Первый в России чемпионат по Enterprise Vibe Coding (EVC) — вайб-кодингу для безопасной работы в корпорациях. Организатор — Альфа-Банк, платформа «Альфа-Ген». Партнёры и жюри: Билайн, Сбер, Яндекс, Redmadrobot, МТС КИОН, Альфа-Капитал.

## Краткое описание
Хакатон длится 39 часов. Участники разрабатывают Модуль безопасности персональных данных — сервис-прокси между системой-потребителем и LLM, выполняющий идентификацию, маскирование и демаскирование ПД. Решения проходят автоматическую проверку (качество кода и нагрузочное тестирование), оценку жюри и защиту перед топ-менеджментом.

## Ключевые темы
- Enterprise Vibe Coding (EVC).
- Безопасность персональных данных при обращении к LLM.
- Модуль-прокси: идентификация → маскирование → демаскирование.
- Автоматическая проверка решений (качество кода, нагрузочное тестирование).
- Оценка жюри и защита перед топ-менеджментом.
