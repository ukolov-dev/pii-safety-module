# Индекс чанков (база знаний хакатона)

Индекс всех чанков в `hackathon_database/chunks/`. Один чанк = один смысловой эпизод.

## Формат записи
```yaml
CH-SRC-NNN-NN:
  источник: SRC-NNN
  тема: <краткое название>
  статус: <новый | в работе | обработан>
  файл: chunks/CH-SRC-NNN-NN.md
```
