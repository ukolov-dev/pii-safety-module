# Реестр конфликтов (база знаний хакатона)

Реестр противоречий в материалах о проведении хакатона. Пространство ID: `CONF-NNN` (NNN — номер). Ведётся по `playbooks/resolve_questions.md`.

## Формат записи
```yaml
CONF-NNN:
  позиция_1: <описание + источник>
  позиция_2: <описание + источник>
  статус: <открыт | в работе | разрешен>
  решение: <принятое решение>
  основание_закрытия: <чем подтверждено закрытие>
  дата: <YYYY-MM-DD>
  ссылки: <SRC-NNN / файлы>
```
