# Подготовка задач разработки

Процедура подготовки задач разработки из согласованных требований.

## Правила
- Задачи готовь **по запросу** пользователя, из **согласованных** требований.
- До создания проверяй дубли и существующую реализацию, если доступен репозиторий.
- Запись в репозиторий разработки — только по поручению пользователя.
- При доработках сохраняй трек, номер и название задачи.
- ID задач — по `database/working/id_rules.md` (`TASK-`).

## Место сохранения
Результат сохраняй в `database/working/developer_tasks.md`.

## Шаблон постановки задачи
```yaml
TASK-001:
  трек: <номер трека в системе разработки>
  название: <краткое название>
  требуемое_изменение: <что нужно изменить/сделать>
  границы: <что входит / что не входит>
  зависимости: <от чего зависит>
  критерии_приемки:
    - AC-ID: <AC-001>
      описание: <проверяемый критерий>
  источник: <REQ-001 / SRC-NNN / CH-SRC-NNN-NN>
  статус: <новая | в работе | готова | принята>
```

## Порядок работы
1. Получи запрос на подготовку задач.
2. Отбери согласованные требования.
3. Проверь дубли и существующую реализацию (если доступен репозиторий).
4. Проверь занятые ID в `developer_tasks.md`; выдай следующий номер.
5. Создай постановку по шаблону.
6. При доработках сохраняй трек, номер и название задачи.
7. Запись в репозиторий разработки — только по поручению пользователя.
