# Создание чеклиста приемки

Процедура создания чеклиста приемки для задачи.

## Чеклист приемки
Для каждой задачи создается чеклист. Каждый проверяемый пункт ссылается на `AC-ID` и `TASK-ID` и содержит предусловия, шаги, ожидаемый результат, фактический результат, статус и комментарий. Окружение и идентификатор проверенной сборки фиксируются отдельно. ID чеклистов — по `database/working/id_rules.md` (`CHK-`).

## Место сохранения
- Каждый чеклист — отдельный файл `database/working/checklists/CHK-001.md`.
- Добавь запись в индекс `database/working/checklists/index.md`.

## Шаблон чеклиста
```yaml
CHK-001:
  задача: <TASK-001>
  окружение: <окружение проверки>
  сборка: <идентификатор проверенной сборки>
  пункты:
    - AC-ID: <AC-001>
      предусловия: <что должно быть готово до проверки>
      шаги:
        - <шаг 1>
        - <шаг 2>
      ожидаемый_результат: <что должно получиться>
      фактический_результат: <что получилось>
      статус: <не проверялось>
      комментарий: <примечания>
```

## Статусы пункта
- **принято** — критерий успешно пройден и принят.
- **провалено** — критерий не пройден.
- **заблокировано** — проверка невозможна из-за блокера.
- **не проверялось** — критерий не проверялся.

## Порядок работы
1. Возьми задачу из постановки.
2. Для каждого критерия приемки (`AC-ID`) создай пункт чеклиста.
3. Проверь занятые ID в `checklists/index.md`; выдай следующий номер.
4. Опиши предусловия, шаги и ожидаемый результат.
5. Зафиксируй окружение и идентификатор сборки.
6. После проверки заполни фактический результат, статус и комментарий.
