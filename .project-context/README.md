# Контекст проекта

`active/` содержит записи знаний и полные тексты импортированных материалов.
Начните с [указателя перенесённых материалов](SOURCE_MAP.md): он связывает исторические пути с актуальными файлами.

- `project.yaml` задаёт маршруты чтения и проверки.
- `source-map.json` содержит машинно-читаемую карту переноса.
- Индексы создаются локально через `npm run context:index` и не публикуются.
- Импортированные документы сохраняют историческое содержимое; их утверждения следует сверять с актуальным кодом.
