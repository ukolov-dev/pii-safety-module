краткое_содержание: >-
  Реализовать единый контракт POST /process, Content-Type application/json. Запрос ProcessRequest:
  обязательные поля payload (string) и payload_id (string). Ответ ProcessResponse: обязательное поле
  result (string). Один эндпоинт обрабатывает и маскирование, и демаскирование. Направление
  определяется по payload_id (ключ корреляции). Первый запрос с новым payload_id — маскирование
  (payload = исходная строка) → вернуть маску и запомнить соответствие. Второй запрос с тем же
  payload_id — демаскирование (payload = маска) → вернуть исходную строку. Ответ всегда
  {"result": "..."}. Поддерживаются HTTPS (self-signed допускается, ssl_verify=false) и HTTP.
  Ответы: 200, 429 (допустим под нагрузкой, ретраи), 4XX, 5XX.
статус: обработан
