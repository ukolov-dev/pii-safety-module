```yaml
  сценарий: <сценарий использования>

  источник: <SRC-NNN / CH-SRC-NNN-NN>
  статус_согласования: предложено
  критерии_приемки:
    - AC-ID: <AC-001>
      описание: <проверяемый критерий>
```

## Правила ID
- Требования: `REQ-001` (глобально уникальные).
- Критерии приемки: `AC-001` (глобально уникальные).
- Следующий номер = максимальный занятый + 1; перед созданием проверяй занятые ID.
- Старые не перенумеровывай, занятые не используй повторно.
- Полные правила — `database/working/id_rules.md`.
