# database — извлеченные знания

Структурированные данные, извлеченные из RAW: чанки, сущности, термины, вопросы, реестры.

## Правила
- Все данные имеют источник (ссылку на файл в `RAW/`).
- Требования не выдумываются — только извлекаются.
- Требования хранятся в `COOKED/requirements/` (см. `manage_requirements.md`).

## Содержимое
- `chunks/` — смысловые чанки источников.
- `registry_*.md` — реестры (источники, решения, вопросы, конфликты, покрытие).
- Тематические файлы: обзор, цели и границы, глоссарий, процессы, данные, архитектура, тестирование.
- `working/` — рабочие файлы: `id_rules.md`, `data_dictionary.md`, `developer_tasks.md`, `checklists/`, `test_results/`, `traceability_matrix.md`.
- `current_context.md`, `navigation.md`, `session_handoff.md` — состояние и маршруты.
