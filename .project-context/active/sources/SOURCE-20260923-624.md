# Реестр решений (база знаний хакатона)

Реестр согласованных решений о проведении хакатона. Пространство ID: `DEC-NNN` (NNN — номер).

## Формат записи
```yaml
DEC-NNN:
  происхождение: <кем и когда принято>
  дата: <YYYY-MM-DD>
  статус: <предложено | согласовано | отклонено | отменено>
  тип: <обязательное | дополнительное | рекомендация>
  ссылки: <источники SRC-NNN и/или файлы>
  описание: <суть решения>
```

## Записи
```yaml
DEC-001:
  происхождение: организаторы хакатона (брифинг)
  дата: 2026-09-22
  статус: согласовано
  тип: рекомендация
  ссылки: SRC-004
  описание: Использование своих кодинговых агентов крайне не рекомендуется; пайплайн проверки выстроен под рекомендуемые инструменты (VS Code, Kilo Code, DeepSeek V4 Flash).

DEC-002:

  дата: 2026-09-22
  статус: согласовано
  тип: обязательное
  ссылки: SRC-004
  описание: Эталонные маски не заданы — участники выбирают маски самостоятельно и описывают их в решении.

DEC-003:
  происхождение: организаторы хакатона (брифинг)
  дата: 2026-09-22
  статус: согласовано

  ссылки: SRC-004
  описание: Язык фильтра — русский; английский по желанию (задача со звёздочкой).

DEC-004:
  происхождение: организаторы хакатона (брифинг)
  дата: 2026-09-22
  статус: согласовано

  ссылки: SRC-004
  описание: Инфраструктура для нагрузочного тестирования — на стороне участников; организаторы мощности не предоставляют, но система автопроверки принимает практически любые URL.

DEC-005:
  происхождение: организаторы хакатона (брифинг)
  дата: 2026-09-22

  тип: обязательное
  ссылки: SRC-004
  описание: Оценка решений использует span-based логику (сравниваются значащие части строк, а не целиком).
```
