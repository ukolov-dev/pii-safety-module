# Шаблон чеклиста приемки

Копируй этот файл для каждого нового чеклиста. Ведётся по `playbooks/create_acceptance_checklist.md`. ID по `database/working/id_rules.md`.

```yaml
CHK-001:
  задача: <TASK-001>
  окружение: <окружение проверки>
  сборка: <идентификатор проверенной сборки>
  пункты:
    - AC-ID: <AC-001>
      предусловия: <что должно быть готово до проверки>
      шаги:
        - <шаг 1>
        - <шаг 2>
      ожидаемый_результат: <что должно получиться>
      фактический_результат: <что получилось>
      статус: <не проверялось>
      комментарий: <примечания>
```

## Статусы пункта
- **принято** — критерий успешно пройден и принят.
- **провалено** — критерий не пройден.
- **заблокировано** — проверка невозможна из-за блокера.
- **не проверялось** — критерий не проверялся.

## Правила ID
- Следующий номер = максимальный занятый + 1.
- Перед созданием проверяй занятые ID в `checklists/index.md`.
- Старые не перенумеровывай, занятые не используй повторно.
