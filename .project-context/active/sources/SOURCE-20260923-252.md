# Обзор

Обзорное описание проекта. Собирается из чанков и источников.

## Назначение
Разработать Модуль безопасности персональных данных, встраиваемый в цепочку взаимодействия «система-потребитель — LLM». Модуль снижает риск утечки ПД при росте числа обращений к LLM, обеспечивает соответствие требованиям законодательства РФ и ЦБ и заменяет разрозненные решения единым стандартом безопасности.

## Краткое описание
Сервис-прокси Core-компонента, который обрабатывает запрос, отправляемый системой-потребителем в LLM, и ответ LLM. В рамках обработки выполняются идентификация персональных данных, их маскирование и демаскирование. Сервис должен выдерживать нагрузку обращений к LLM, отвечать быстро и качественно.

## Ключевые критерии качества (из «Образ решения»)
- Насколько хорошо сервис находит информацию, которую нельзя передавать без обработки.
- Насколько мало ложных срабатываний.
- Сохраняется ли после обработки смысл запроса для AI-модели.
- Можно ли управлять правилами для разных систем.
- Насколько просто подключить нового потребителя.
- Что происходит при ошибках или недоступности отдельных компонентов.
- Не попадают ли исходные защищаемые данные в логи и технические метрики.

## Ключевые темы
- Идентификация → маскирование → демаскирование персональных данных.
- Прокси между системой-потребителем и LLM.
- Безопасность и приватность (отсутствие утечек, шифрование, минимизация данных).
- Производительность (Latency, RPS, TPS).
- Гибкая настройка для нескольких систем-потребителей.
- Минимум ложных срабатываний, сохранение смысла запроса, отсутствие защищаемых данных в логах.
