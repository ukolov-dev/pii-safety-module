# Цели и границы

Цели проекта и его границы (что входит, что не входит). Собирается из чанков и источников.

## Цели
- Создать модуль защиты ПД, встраиваемый в цепочку «система-потребитель — LLM».
- Снизить риск утечки ПД при росте числа обращений к LLM.
- Обеспечить соответствие требованиям законодательства РФ и ЦБ.
- Заменить разрозненные решения единым стандартом безопасности.
- Выполнять роль прокси Core-компонента, выдерживать нагрузку обращений к LLM.

## Границы (входит)
- Идентификация, маскирование и демаскирование персональных данных.
- Обработка запроса в LLM и ответа LLM.
- Поддержка нескольких систем-потребителей с индивидуальными настройками.
- Логирование и метрики (Latency, RPS, TPS).
- Реализация контракта API POST /process.
- Минимизация ложных срабатываний.
- Сохранение смысла запроса для AI-модели после обработки.
- Отсутствие исходных защищаемых данных в логах и технических метриках.
- Простота подключения нового потребителя.

## Границы (не входит)
- UI не обязателен (модуль работает «под капотом»; UI допустим, но не требуется).
- Объём кода не оценивается.
