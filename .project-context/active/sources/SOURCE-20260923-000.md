# Текущая опубликованная версия

По запросу пользователя опубликована восстановленная сборка v6 с активным детектором `v3.26`. Версия Python-пакета и API — `0.1.0`. Источник состава и проверок: `solution/VERSION.md`.

Перед публикацией изолированно прошли 201 тест, Ruff и mypy. Для самодостаточного запуска тестов добавлены необходимые модули `proposals/`. Нагрузочный прогон не повторялся; результаты v6 исторические.

Текущая конфигурация: одна API-реплика и Redis. Описание двух реплик, Nginx, `/metrics`, проверки API-ключа или readiness через Redis PING относится к более поздним экспериментам и не описывает эту восстановленную сборку. Сверяйте эксплуатационные утверждения с `solution/SECURITY_AND_OPERATIONS.md` и кодом.
