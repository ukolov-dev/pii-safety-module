# Реестр открытых вопросов

Реестр открытых пунктов, требующих уточнения. Пространство ID: `Q-NNN` (NNN — номер). Ведётся по `playbooks/resolve_questions.md`.

## Формат записи
```yaml
Q-NNN:
  суть: <что неизвестно>
  блокируемые_пункты: <зависимые требования/решения>
  ответственный: <кто решает>
  статус: <открыт | в работе | закрыт>
  ответ: <принятый ответ>
  подтверждение_ответа: <источник/документ, подтверждающий ответ>
  дата: <YYYY-MM-DD>
  ссылки: <SRC-NNN / файлы>
```

## Записи
```yaml
Q-001:
  суть: Обязан ли участник использовать модель DeepSeek V4 Flash (Альфа-Ген) как инструмент разработки?

  ответ: настоятельно рекомендуется для равных условий, но не строгое требование
  подтверждение_ответа: транскрипт брифинга (SRC-004), реплика Ивана Корсея
  дата: 2026-09-22
  ссылки: SRC-004
```
