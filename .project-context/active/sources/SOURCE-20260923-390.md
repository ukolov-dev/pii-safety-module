# Ведение словаря данных

Процедура ведения словаря данных проекта.

## Словарь данных
Словарь данных описывает сущности и их поля. Не заполняй неизвестное догадками — оставляй поле пустым или помечай как «неизвестно».

## Место сохранения
Результат сохраняй в `database/working/data_dictionary.md`.

## Формат записи
```yaml
сущность:
  поле:
    тип: <тип данных>
    обязательность: <да | нет | неизвестно>
    проверки: <правила валидации>
    единицы: <единицы измерения>
    формула: <формула расчета>
    источник: <SRC-NNN / CH-SRC-NNN-NN>
```

## Поля
- **сущность** — название сущности.
- **поле** — название поля.
- **тип** — тип данных.
- **обязательность** — обязательно ли поле.
- **проверки** — правила валидации.
- **единицы** — единицы измерения.
- **формула** — формула расчета (если применимо).
- **источник** — ссылка на источник/чанк.

## Правила
- Не заполняй неизвестное догадками.
- Каждое поле имеет источник.
- После значимых изменений обновляй `database/current_context.md`.
