# Глоссарий

Термины и определения проекта. Собирается из чанков и источников. Ведётся по `playbooks/maintain_glossary.md`.

## Формат записи
```yaml
термин:
  определение: <значение>
  источник: <SRC-NNN / CH-SRC-NNN-NN>
  статус_подтверждения: <подтверждено | на уточнении>
```

## Термины
```yaml
LLM:
  определение: Large Language Model — большая языковая модель, к которой обращается система-потребитель.
  источник: SRC-001
  статус_подтверждения: подтверждено

система-потребитель:
  определение: Система, которая отправляет запросы в LLM и получает ответы; взаимодействует с модулем через прокси.
  источник: SRC-001
  статус_подтверждения: подтверждено

идентификация ПД:
  определение: Определение типа персональных данных в тексте.
  источник: SRC-001
  статус_подтверждения: подтверждено

маскирование:
  определение: Замена персональных данных на маску (замаскированную строку).
  источник: SRC-001
  статус_подтверждения: подтверждено

демаскирование:
  определение: Преобразование замаскированного текста в незамаскированный с сохранением местоположения знаков.
  источник: SRC-001
  статус_подтверждения: подтверждено

токенизация:
  определение: Замена персональных данных токенами (дополнительная реализация).
  источник: SRC-001
  статус_подтверждения: подтверждено

детокенизация:
  определение: Обратное преобразование токенов в исходные данные (дополнительная реализация).
  источник: SRC-001
  статус_подтверждения: подтверждено

Latency:
  определение: Задержка ответа сервиса. Численные требования — см. раздел «Численные требования».
  источник: SRC-001
  статус_подтверждения: подтверждено

RPS:
  определение: Requests Per Second — количество запросов в секунду. Численные требования — см. раздел «Численные требования».
  источник: SRC-001
  статус_подтверждения: подтверждено

TPS:
  определение: Tokens Per Second — количество токенов в секунду (метрика).
  источник: SRC-001
  статус_подтверждения: подтверждено

span-based логика:
  определение: Метод оценки, при котором сравниваются значащие части строк (спаны), а не строки целиком.
  источник: SRC-004
  статус_подтверждения: подтверждено

payload_id:
  определение: Идентификатор корреляции пары «маскирование → демаскирование» в контракте API.
  источник: SRC-001
  статус_подтверждения: подтверждено
```

## Численные требования (отдельно от определений)
- **Latency**: не более 1 секунды (требование, SRC-001); в Приложении B — ориентир, не жёсткий лимит (SRC-001). См. Q-003.
- **RPS**: целевое 1000 (SRC-001); дополнительно 2000 (SRC-001).
- **Точность**: не менее 95% (SRC-001).
- **Контекст**: до 100 000 токенов (SRC-001).
