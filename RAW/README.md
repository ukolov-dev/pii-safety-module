# RAW — исходные материалы

Сюда складываются необработанные исходники: заметки, скриншоты, тексты, ссылки, файлы от заказчика и команды.

## Правила
- Файлы не редактируются и не структурируются.
- Каждый материал — отдельный файл с понятным именем.
- При добавлении материала обновляйте этот README (список ниже).

## Материалы
- `ds.pdf` — ТЗ трека «Модуль безопасности персональных данных» (условия, автоматическая проверка, контракт API, приложения A и B).
- `requirements.md` — Регламент хакатона и ТЗ на систему.
- `Сегодня_все_команды,_работающие_с_L.txt` — онбординг (проблематика, требования, автоматическая проверка).
- `2026-09-22-opening-transcript.txt` — транскрипт брифинга открытия хакатона.
