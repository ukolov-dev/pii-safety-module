# Отчёт об улучшении детектора v3.3

Дата прогона: 2026-09-23.

## Решение о продвижении

В production продвинут кандидат **v3.3**. Критерий продвижения — рост F1 не менее
чем на 10 процентных пунктов на новом закрытом holdout без ухудшения round-trip и
с сохранением SLA.

| Метрика на sealed holdout v5 | v2 baseline | v3.3 | Изменение |
|---|---:|---:|---:|
| Precision | 89,47% | 91,07% | +1,60 п.п. |
| Recall | 44,74% | 67,11% | +22,37 п.п. |
| F1 | 59,65% | 77,27% | **+17,62 п.п.** |
| Exact mask | 37/68 | 45/68 | +8 случаев |
| Exact round-trip | 68/68 | 68/68 | без изменений |

Кандидат v3.4 отклонён: на том же закрытом holdout он дал F1 68,80%, то есть
только +9,15 п.п. Варианты v3.1 и v3.2 также не достигли порога +10 п.п. на
предыдущем закрытом holdout v4.

## Состав изменения

- production API переключён на `app/detection/detector_v3_3.py`;
- сохранены отдельные слои v3 и v3.2 для прозрачности правил;
- добавлены quality gates для blind/stress/sealed наборов;
- устранён перенос семантического контекста даты между предложениями;
- добавлен быстрый путь для больших текстов без v3.3-маркеров.
