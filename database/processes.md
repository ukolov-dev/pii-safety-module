# Процессы

Описание процессов проекта. Собирается из чанков и источников.

## Формат записи
```yaml
процесс:
  описание: <как работает>
  вход: <что требуется>
  выход: <что получается>
  источник: <SRC-NNN>
```

## Процессы
```yaml
обработка_запроса_в_LLM:
  описание: Система-потребитель отправляет запрос в LLM через модуль; модуль идентифицирует ПД, маскирует их и передаёт в LLM.
  вход: исходный запрос с ПД
  выход: замаскированный запрос для LLM
  источник: SRC-001

обработка_ответа_LLM:
  описание: Модуль обрабатывает ответ LLM, демаскирует ПД и возвращает результат системе-потребителю.
  вход: ответ LLM с замаскированными ПД
  выход: демаскированный ответ для системы-потребителя
  источник: SRC-001

маскирование:
  описание: Замена ПД на маску с учётом вариаций написания (регистр, формат дат, разделяющие слова).
  вход: текст с ПД
  выход: замаскированный текст
  источник: SRC-001

демаскирование:
  описание: Преобразование замаскированного текста в исходный с сохранением местоположения знаков.
  вход: замаскированный текст
  выход: исходный текст
  источник: SRC-001

контракт_api_process:
  описание: POST /process обрабатывает и маскирование, и демаскирование; направление определяется по payload_id (ключ корреляции). Первый запрос с новым payload_id — маскирование; второй с тем же payload_id — демаскирование.
  вход: {"payload": "<строка>", "payload_id": "<идентификатор>"}
  выход: {"result": "<строка>"}
  источник: SRC-001
```
