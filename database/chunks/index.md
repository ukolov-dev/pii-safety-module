# Индекс чанков

Индекс всех чанков в `database/chunks/`. Один чанк = один смысловой эпизод.

## Формат записи
```yaml
CH-SRC-NNN-NN:
  источник: SRC-NNN
  тема: <краткое название>
  статус: <новый | в работе | обработан>
  файл: chunks/CH-SRC-NNN-NN.md
```
