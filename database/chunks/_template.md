# Шаблон чанка

Один чанк = один смысловой эпизод (решение, требование, вопрос или замечание).
Копируй этот файл для каждого нового чанка. Не заполняй поля вымышленными данными.

```yaml
id: CH-SRC-NNN-NN
источник: SRC-NNN
точный_локатор: <строка/раздел/страница/временная метка>
тема: <краткое название эпизода>
краткое_содержание: <суть эпизода>
статус: новый
связанные_требования: []
связанные_вопросы: []
```

## Пояснения полей
- **id** — `CH-SRC-NNN-NN`: `SRC-NNN` — источник, `NN` — порядковый номер чанка.
- **источник** — ID источника из `database/registry_sources.md`.
- **точный_локатор** — точное место в источнике.
- **тема** — краткое название эпизода.
- **краткое_содержание** — суть эпизода.
- **статус** — `новый | в работе | обработан`.
- **связанные_требования** — ссылки на требования (если есть).
- **связанные_вопросы** — ссылки на `Q-NNN` (если есть).
