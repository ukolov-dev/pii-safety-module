# Передача контекста следующей сессии

Короткий шаблон для передачи состояния между сессиями. Заполняй перед сменой сессии. Не копируй всю историю — только суть.

## Шаблон
```yaml
цель: <текущая цель сессии>
сделано: <кратко, что завершено>
решения: <принятые решения>
открытое: <незавершенное и блокеры>
точка_продолжения: <откуда продолжить разбор источника, если он в обработке>
нужные_файлы: <список файлов для чтения в следующей сессии>
следующий_шаг: <что делать дальше>
```
