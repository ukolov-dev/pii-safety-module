# Матрица трассируемости

Постоянный рабочий файл матрицы трассируемости. Ведётся по `playbooks/maintain_traceability.md`. ID по `database/working/id_rules.md`.

Связывает: источник > чанк > требование > задача > критерий > конкретная проверка.

## Формат записи
```yaml
REQ-001:
  источник: SRC-NNN
  чанк: CH-SRC-NNN-NN
  задачи:
    - TASK-ID: <TASK-001>
      критерии:
        - AC-ID: <AC-001>
          проверки:
            - RESULT-ID: <RES-001>
              статус: <принято | провалено | заблокировано | не проверялось>
```

## Правила
- Связывай только реально существующие записи.
- Отсутствующую задачу или проверку не придумывай — оставляй ячейку пустой.
- Один критерий может иметь несколько задач и повторных проверок (`RES-`).
- Каждая повторная проверка имеет собственный `RES-` и сохраняет историю предыдущих результатов.
- При изменении требования показывай затронутые документы и задачи.
