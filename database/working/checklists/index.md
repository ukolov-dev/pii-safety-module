# Чеклисты приемки

Индекс чеклистов приемки. Каждый чеклист — отдельный файл в `database/working/checklists/`. Ведётся по `playbooks/create_acceptance_checklist.md`. ID по `database/working/id_rules.md`.

## Формат записи
```yaml
CHK-001:
  задача: <TASK-001>
  файл: checklists/CHK-001.md
```
