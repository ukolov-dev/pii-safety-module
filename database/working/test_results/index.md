# Результаты проверок

Индекс результатов проверок. Каждый результат — отдельный файл в `database/working/test_results/`. Ведётся по `playbooks/process_test_results.md`. ID по `database/working/id_rules.md`.

## Формат записи
```yaml
RES-001:
  чеклист: <CHK-001>
  задача: <TASK-001>
  файл: test_results/RES-001.md
```
