# Задачи разработки

Постоянный рабочий файл задач разработки. Ведётся по `playbooks/prepare_developer_tasks.md`. ID по `database/working/id_rules.md`.

## Формат записи
```yaml
TASK-001:
  трек: <номер трека в системе разработки>
  название: <краткое название>
  требуемое_изменение: <что нужно изменить/сделать>
  границы: <что входит / что не входит>
  зависимости: <от чего зависит>
  критерии_приемки:
    - AC-ID: <AC-001>
      описание: <проверяемый критерий>
  источник: <REQ-001 / SRC-NNN / CH-SRC-NNN-NN>
  статус: <новая | в работе | готова | принята>
```

## Правила ID
- Следующий номер = максимальный занятый + 1.
- Перед созданием проверяй занятые ID.
- Старые не перенумеровывай, занятые не используй повторно.
- При доработках сохраняй трек, номер и название.
