# Реестр покрытия материалов

Реестр покрытия источников при обработке на чанки. Пространство ID: `COV-NNN` (NNN — номер). Ведётся по `playbooks/process_source.md`.

## Формат записи
```yaml
COV-NNN:
  источник: SRC-NNN
  обработанные_диапазоны: <строки/разделы, уже разобранные>
  связанные_чанки: [<CH-SRC-NNN-NN>]
  пропуски: <необработанные участки внутри обработанных диапазонов>
  оставшаяся_часть: <что ещё не обработано>
  точка_продолжения: <откуда продолжить разбор>
  статус: <в обработке | обработан>
  дата: <YYYY-MM-DD>
```

## Статусы
- **в обработке** — разбор незавершён, есть оставшаяся часть.
- **обработан** — полное покрытие проверено, пропусков нет.

## Правила
- Статус «обработан» ставь только после проверки полного покрытия.
- Для незавершённого разбора используй «в обработке».
- Учитывай смысловые границы: не разрывай эпизод посередине.
- При продолжении проверяй дубли (не создавай повторные чанки).
