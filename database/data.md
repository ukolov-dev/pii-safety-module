# Данные

Описание данных проекта: сущности, поля, связи. Собирается из чанков и источников.

## Формат записи
```yaml
сущность:
  поля: <список полей>
  связи: <связи с другими сущностями>
  источник: <SRC-NNN>
```

## Сущности
```yaml
персональные_данные:
  поля: [ФИО, дата рождения, место рождения, серия и номер паспорта, гражданство, орган выдачи паспорта, код подразделения, дата выдачи паспорта, серия и номер водительского удостоверения, адрес, email, номер телефона, ИНН, номер платёжной банковской карты, CVV-код, ПИН-код карты, имя держателя карты]
  связи: идентифицируются, маскируются, демаскируются модулем
  источник: SRC-001

адрес:
  поля: [страна, индекс, город, улица, дом, квартира]
  связи: часть персональных данных
  источник: SRC-001

запрос_процесс:
  поля: [payload (string, обязательное), payload_id (string, обязательное)]
  связи: контракт API POST /process
  источник: SRC-001

ответ_процесс:
  поля: [result (string, обязательное)]
  связи: контракт API POST /process
  источник: SRC-001
```
