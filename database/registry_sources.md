# Реестр источников

Реестр исходных материалов. Каждый источник получает ID вида `SRC-NNN` (NNN — номер).

## Формат записи
```yaml
SRC-NNN:
  происхождение: <откуда получен>
  дата: <YYYY-MM-DD>
  статус: <новый | в обработке | обработан | отклонен>
  ссылки: <пути к файлам в RAW/ или внешние ссылки>
  описание: <краткое описание>
```

## Записи
```yaml
SRC-001:
  происхождение: задание на хакатон (ТЗ трека)
  дата: 2026-09-22
  статус: обработан
  ссылки: RAW/ds.pdf
  описание: ТЗ трека «Модуль безопасности персональных данных» — требования к системе, контракт API, критерии проверки.

SRC-002:
  происхождение: задание на хакатон (регламент и ТЗ)
  дата: 2026-09-22
  статус: обработан
  ссылки: RAW/requirements.md
  описание: ТЗ на систему (назначение, основные требования, типы ПД, надёжность, дополнительные требования).

SRC-003:
  происхождение: онбординг
  дата: 2026-09-22
  статус: обработан
  ссылки: RAW/Сегодня_все_команды,_работающие_с_L.txt
  описание: Онбординг — функциональные и нефункциональные требования к системе, типы ПД, автопроверка.

SRC-004:
  происхождение: транскрипт брифинга открытия
  дата: 2026-09-22
  статус: обработан
  ссылки: RAW/2026-09-22-opening-transcript.txt
  описание: Транскрипт брифинга — уточнения по требованиям к системе, критерии оценки, ответы на вопросы.

SRC-005:
  происхождение: авторизованный портал участника хакатона

```
