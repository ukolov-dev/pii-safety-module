# COOKED — подготовленные документы

Готовые артефакты: итоговые спецификации, презентации, чек-листы, документы для использования.

## Правила
- Документы готовы к использованию и распространению.
- Каждый документ ссылается на источники в `RAW/` и `database/`.
- Собираются из данных database.

## Содержимое
- `requirements/current_specification.md` — текущая спецификация требований (актуальная; исторические версии — отдельные неизменяемые снимки).
